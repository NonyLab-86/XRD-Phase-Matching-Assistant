Method and limitations

  • Experimental files need two numeric columns: 2θ and intensity.
  • Reference TXT/RTF files should contain metadata and a peak list whose final numeric columns are 2θ and relative intensity. Two-column reference patterns are supported.
  • Counts represent experimental local maxima with a nearest reference reflection within the tolerance. One experimental peak is counted at most once per reference.
  • Phase labels and metadata extraction are heuristic. Matching does not prove phase identity or phase fraction.
  • RTF files are supported as text. For PDF references, export the peak table to TXT/RTF first. XLSX input/output requires the SheetJS library from a public CDN.
